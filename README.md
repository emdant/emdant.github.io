# emdant.github.io

Personal academic homepage of Marco D'Antonio, built with the [Minimal Light](https://github.com/yaoyao-liu/minimal-light) Jekyll theme (MIT) and hosted on GitHub Pages.

## Where to edit
| What | File |
|---|---|
| Name, title, e-mail, links, CV link | `_config.yml` |
| Bio, research interests, news | `index.md` |
| Publications | `_data/publications.yml` |
| Service / reviewing | `_includes/services.md` |
| Photo | `assets/img/avatar.png` (square) |
| CV | `assets/files/cv.pdf` (then uncomment `cv_link` in `_config.yml`) |

Search for `TODO` to find the remaining placeholders. Every push to `main` rebuilds the site automatically.
